# somincola.com

Website for **Somincola LLC** — an independent software studio crafting focused, privacy-respecting apps for Apple
platforms and the open social web.

Built with [Astro](https://astro.build) and Tailwind CSS, deployed on Cloudflare Pages.

```bash
npm install
npm run dev     # http://localhost:4321
npm run check   # types, lint, formatting
npm run build   # → dist/
```

See [CLAUDE.md](./CLAUDE.md) for architecture and design-system notes.
